# 💻 Landing Page - Cursos SerFrontEnd

Projeto de desenvolvimento front-end focado na construção de um layout moderno e responsivo para exibição de módulos/cursos de programação web. Desenvolvido como prática de fixação dos conceitos fundamentais de HTML5 e CSS3.

---

## 🎯 Objetivo do Projeto

O objetivo principal deste projeto é aplicar técnicas de estruturação semântica e estilização para criar um painel de cartões alinhado com Flexbox, apresentando os tópicos essenciais de formação no desenvolvimento front-end:

* **Seletores:** Domínio de seleção de elementos e especificidade CSS.
* **Posicionamento:** Manipulação de elementos na página.
* **Fontes:** Tipografia web e hierarquia visual de textos.
* **Flexbox:** Construção de layout flexível, distribuição de espaço e alinhamento dos cards.
* **Semântica:** Estruturação limpa e acessível com tags HTML5 apropriadas.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica da página (`<header>`, `<main>`, `<section>`).
* **CSS3:** Estilização visual, imagem de fundo, efeitos nos cards e organização do layout utilizando puramente **Flexbox**.
